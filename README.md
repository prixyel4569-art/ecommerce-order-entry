# 单号录入

一个面向 Windows 的轻量级单号登记工具。无需安装额外软件，双击即可运行；每天自动创建独立文件夹，并将单号保存为本地 Markdown 表格。

数据默认保存在程序所在目录，不上传网络，适合个人或小团队进行日常订单号、商品 ID 等内容的登记和核对。

## 安全说明与杀毒软件误报

本项目代码公开、可直接查看和审计，**不包含木马、后门、键盘记录、数据窃取或远程控制功能**。程序只在本机执行以下操作：

- 读取和写入 `单号` 目录下的 Markdown 记录文件。
- 创建每日日期文件夹和记录文件。
- 在用户点击后调用 Windows 资源管理器打开对应文件夹。
- 自检时在系统临时目录创建测试文件，并在测试结束后清理该临时目录。
- 不联网、不上传单号、不采集个人信息、不下载外部程序、不执行远程代码。

部分杀毒软件或 Windows Defender 可能将 `.bat` 启动器和未签名的 PowerShell 脚本识别为风险。这是脚本类工具常见的启发式误报，原因通常包括：

- `.ps1` 文件没有商业代码签名。
- `启动单号录入.bat` 使用 PowerShell 启动本地脚本。
- 启动命令包含 `-ExecutionPolicy Bypass`，用于避免普通电脑上的脚本执行策略阻止程序运行。

如果出现“木马”或“高危脚本”提示，请先确认文件来自本项目仓库，并可直接打开 `danhao.ps1` 检查全部代码。不要关闭整个杀毒软件，也不要信任来源不明的二次打包版本。仅在确认文件来源和内容后，才考虑对该项目目录添加安全软件例外。

## 功能特点

- **每日自动归档**：按照 `单号\yyyy-MM-dd` 自动创建当天文件夹和 `单号记录.md`。
- **批量录入**：支持每行一个单号，也支持空格、逗号、中文逗号、分号、顿号和竖线分隔。
- **自动去重**：同一天内已经登记过的单号会自动跳过。
- **备注支持**：保存当前批次时可附上可选备注。
- **差异核对**：粘贴 Excel 商品 ID 整列，自动对比缺少和多余的单号，并可一键补登记。
- **历史查看**：通过右上角“查看日期”下拉框查看过往日期的记录。
- **历史只读**：查看历史记录时录入区自动锁定，切回“今天”后即可继续录入，避免误改旧数据。
- **快速复制**：双击列表中的记录可复制对应单号。
- **跨日切换**：程序跨夜保持打开时，重新激活窗口或再次保存会自动切换到新日期。
- **纯本地存储**：记录为普通 Markdown 文件，便于检索、备份和版本管理。

## 运行环境

- Windows 10 或 Windows 11
- Windows PowerShell 5.1 或更高版本
- 无需安装 Python、Node.js 或其他运行环境

## 快速开始

1. 下载并解压本项目。
2. 双击 `启动单号录入.bat`。
3. 在输入框中粘贴单号，每行一个。
4. 根据需要填写备注。
5. 点击“保存与追加”，或按 `Ctrl + Enter`。

首次运行会在程序所在目录自动创建当天文件夹：

```text
单号录入\
├── danhao.ps1
├── 启动单号录入.bat
├── README.md
└── 单号\
    └── 2026-11-05\
        └── 单号记录.md
```

第二天启动时，会自动创建新的日期文件夹，例如：

```text
单号\
└── 2026-11-06\
    └── 单号记录.md
```

## 查看历史记录

1. 在界面右上角的“查看日期”下拉框中选择日期。
2. 列表会显示该日期已登记的全部单号。
3. 点击“打开所选日期文件夹”可直接访问对应目录。
4. 历史模式下录入、保存和差异核对功能会自动锁定。
5. 在日期下拉框中重新选择带“（今天）”的日期，即可恢复录入。

日期下拉框会自动扫描 `单号` 目录下所有符合 `yyyy-MM-dd` 格式的历史文件夹。

## 数据格式

每天的记录保存在独立 Markdown 文件中，内容格式如下：

```markdown
# 单号记录 - 2026-11-05

| 序号 | 单号 | 备注 |
| ---- | ---- | ---- |
| 1 | ORDER-001 | 示例备注 |
| 2 | ORDER-002 | |
```

文件使用 UTF-8 编码，可以直接用文本编辑器、VS Code、Typora 或支持 Markdown 的工具打开。

## 命令行用法

如需进行调试或批处理，可以直接调用 PowerShell 脚本。

打开今日记录：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\danhao.ps1 -List
```

追加单号：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\danhao.ps1 -Add "ORDER-001","ORDER-002"
```

执行自检：

```powershell
powershell.exe -NoProfile -STA -ExecutionPolicy Bypass -File .\danhao.ps1 -SelfTest
```

自检会验证今日目录、模拟明日目录的自动创建、历史日期扫描以及历史只读模式。

## 常见问题

### 双击后没有出现窗口

请确认 `danhao.ps1` 和 `启动单号录入.bat` 位于同一目录，并且没有被杀毒软件拦截。

### 记录文件在哪里

记录默认位于：

```text
单号录入\单号\yyyy-MM-dd\单号记录.md
```

文件位置不依赖系统桌面或用户目录，移动整个项目文件夹即可一并迁移数据。

### 为什么历史记录不能录入

历史日期采用只读模式，用于防止误改旧记录。选择带“（今天）”的日期后即可继续录入。

### 数据是否会联网

不会。本工具只在本地读写 Markdown 文件，不包含网络上传功能。
